# Application Security and Azure DevOps Demo

A demonstration repository for application-security testing and deployment through Azure DevOps.

## Scope

Use the project to explore how security checks can fit into a delivery workflow. The repository description identifies this as a demo, not a production security control.

## Before relying on results

Review the actual pipeline tasks, configuration, and test coverage in this repository. Security findings depend on the tools and checks that are configured; a successful pipeline alone does not certify an application as secure.
